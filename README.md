## 🚀 Featured Project

### 🏥 [DoctorCare — Healthcare Booking Platform](https://github.com/NTHieu-bk/doctor-booking)

A healthcare appointment booking application built to explore
full-stack development, database integrity, authorization, and
concurrent booking scenarios.

**Key engineering work:**

- Built the backend with **ASP.NET Core and Clean Architecture**, separating
  domain, application, infrastructure, and API concerns.
- Implemented an appointment lifecycle with
  `Pending`, `Confirmed`, `Cancelled`, `Rejected`, and `Completed` states,
  including booking and cancellation rules.
- Prevented active-slot double booking using application-level validation
  together with a PostgreSQL **partial unique index**, returning
  `409 Conflict` when concurrent requests collide.
- Implemented JWT-based role and ownership authorization to restrict
  patient and doctor operations, with automated tests covering core
  domain and API behavior.

**Tech:** `C#` · `ASP.NET Core` · `EF Core` · `PostgreSQL` · `Docker` · `xUnit`
